## Supported File Formats

- **Scintrex CG-5** observation files
- **Scintrex CG-6** observation files (LynxLG v1/v2, CG6 Solo format)
- **Station tables** in OESGN format or CSV
- **Gravimeter metadata** as JSON files
- **Correction time series** in TSF (Tsoft) format
